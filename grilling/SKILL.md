---
name: grilling
description: Grill the user relentlessly about a plan, decision, or idea. Also use when the user wants to stress-test their thinking, or uses any 'grill' trigger phrases.
---

Interview the user relentlessly about the plan, decision, idea, or task at hand until you and the user reach a shared understanding. Walk down each branch of the decision tree, resolving dependencies between decisions one by one. Use this process to close important gaps and resolve ambiguity. For each question, provide your recommended answer.

Ask the questions one at a time, waiting for feedback on each question before continuing. The user may ask clarifying questions before giving their answer. Do not move to the next question until the current one has been answered. Asking multiple questions at once is bewildering.

If a *fact* can be found by exploring the environment (filesystem, tools, etc.), look it up rather than asking the user. The *decisions*, though, belong to the user — put each one to the user and wait for their answer.

Once the important gaps and ambiguities are resolved, briefly summarize the resulting shared understanding and ask the user to confirm it. Do not act on the task until the user confirms the shared understanding.

## Question Format

For each question, use the following structure:

[Brief context necessary to understand the question]

**QX.** [Question]

[Your recommendation and brief reasoning]
